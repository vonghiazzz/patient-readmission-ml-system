# Data Dictionary

## Dataset

Diabetes 130-US Hospitals for Years 1999–2008.

The raw patient-level dataset is stored locally under `data/raw/` and is
excluded from Git. The validated working dataset is generated by the data
pipeline.

## Prediction target

| Source value | `readmitted_30d` |
|---|---:|
| `<30` | 1 |
| `>30` | 0 |
| `NO` | 0 |

The model predicts whether a patient will be readmitted within 30 days.

## Excluded columns

| Column | Reason |
|---|---|
| `readmitted` | Source target column |
| `readmitted_30d` | Derived target column |
| `encounter_id` | Encounter identifier; not a predictive feature |
| `patient_nbr` | Patient identifier; used for group-aware splitting only |

## Required fields

| Column | Type/category | Description | Validation rule |
|---|---|---|---|
| `encounter_id` | Integer/identifier | Unique encounter identifier | Required; non-negative |
| `patient_nbr` | Integer/identifier | Patient identifier | Required; non-negative |
| `race` | Categorical | Patient race | Required; missing values reported |
| `gender` | Categorical | Patient gender | Required |
| `age` | Ordered categorical | Patient age interval | Required |
| `time_in_hospital` | Integer | Number of hospital days | Required; non-negative |
| `num_lab_procedures` | Integer | Number of laboratory procedures | Required; non-negative |
| `num_procedures` | Integer | Number of non-lab procedures | Required; non-negative |
| `num_medications` | Integer | Number of medications | Required; non-negative |
| `number_outpatient` | Integer | Outpatient visits in preceding year | Required; non-negative |
| `number_emergency` | Integer | Emergency visits in preceding year | Required; non-negative |
| `number_inpatient` | Integer | Inpatient visits in preceding year | Required; non-negative |
| `number_diagnoses` | Integer | Number of diagnoses | Required; non-negative |
| `readmitted` | Categorical target | Original readmission label | One of `<30`, `>30`, `NO` |

## Missing-value handling

Special missing-value tokens such as `?` are converted to null values during
ingestion. Missing-value thresholds are configured in
`configs/data_quality.yaml`.

## Duplicate handling

Duplicate checks are configured in `configs/data_quality.yaml`. Encounter-level
duplicates are checked using `encounter_id`.

## Generated features

| Feature | Definition |
|---|---|
| `service_utilization` | `number_outpatient + number_emergency + number_inpatient` |
| `total_clinical_activities` | `num_lab_procedures + num_procedures` |
